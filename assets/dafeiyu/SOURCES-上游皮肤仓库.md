## 价格说明
账房鱼面板的"预期价格"按 DeepSeek API 官方价估算（deepseek-chat：
输入未命中 ¥2 / 缓存命中 ¥0.5 / 输出 ¥8 每百万 token），实际以你的模型与套餐为准；
可在浏览器 localStorage 覆盖费率：`dsh-fish-rates`。
