## 一、抽样方法

- 分层：每 线×type 层内**固定步长 3**（层内第 0、3、6…条）取样，可复现；
- 实际样本 **85 / 243 = 35.0%**（≥30% ✓）。分层明细：fate main 11/32、fate context 24/72、fate critical 6/17、study context 8/22、career context 7/21、study critical 1/2、career critical 1/3、rescue 四线各 1/2、love/friend/health context 各 8/22~8/24。

## 二、六项人工判据（逐条过审）

1. 年代锚具体可感（物件/物价/流行语，非空泛年代词）；
2. 地域差异句成立（南北/城乡对照句自然入文，非贴标签）；
3. 家境呼应细节成立（与家境档位呼应的具体细节）；
4. 五感真实非凑数（感官词服务于场景，非硬嵌）；
5. 互引有实指（支线对主线/其他支线的 NPC 或前事件回指；fate 为主线豁免）；
6. 叙述与选项及 aftermath 无矛盾（含**不预演选项行为**）。
