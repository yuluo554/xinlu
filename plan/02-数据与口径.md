# 02 · 数据与口径（单一定义源）

> 本档是全部数值口径的**唯一事实源**。引擎代码只实现口径、不再表述口径；数据文件只携带数值、不复写口径文字。发现第二份表述 = 缺陷，进 backlog。

## 一、四维倾向值口径

| 项 | 定义 |
|---|---|
| 维度 | `ei`（E-I 外向-内向）、`sn`（S-N 实感-直觉）、`tf`（T-F 思考-情感）、`jp`（J-P 判断-知觉） |
| 值域 | 闭区间 [0, 100] 的整数，50 = 中立；引擎每次偏移后**钳制**到值域 |
| 字母判定 | `ei>50 → E，<50 → I`；其余三维同构：`sn>50 → S，tf>50 → F，jp>50 → J`；`=50` 时按出生环境初始值的历史符号裁定（引擎实现，不在文案中另述） |
| 偏移口径 | **常规选项 \|Δ\| ≤ 3，重大抉择（critical）\|Δ\| ≤ 8**，整数步进 |
| 隐性权重 | 部分选项不直接偏移四维，只落 `flags`（如 `rebel`、`conform`），供后续事件前置条件与结局判定引用 |

## 二、事件库 schema（`src/data/events.json`）

```jsonc
{
  "id": "youth-014",            // 全库唯一，{stage缩写}-{序号}
  "stage": "youth",             // 8 阶段枚举之一
  "type": "main",               // main 主线必经 | context 情境随机 | critical 重大抉择
  "ageHint": "22岁",            // 展示用
  "pre": ["rebel"],             // 可选：前置 flags（须由更早事件定义，防死锁）
  "text": "……",                 // 事件文案（原创）
  "options": [
    {
      "text": "……",
      "deltas": { "ei": 2, "tf": -3 },   // 至少一维非零，或落 flag；超口径 = 校验红
      "flag": "rebel",                    // 可选
      "aftermath": "……"                   // 可选：选择后的即时反馈文案
    }
  ]
}
```

**校验脚本必须查**（`scripts/validate-data.mjs`，M1 建立）：

1. id 唯一；stage/type 属于枚举；每事件 `options.length ≥ 2`；
2. 每选项至少一维 delta 非零或带 flag；`|Δ|` 不超口径（常规 ≤3 / critical ≤8）；
3. `pre` 引用的 flag 存在且定义事件在本事件之前（**防不可达死锁**）；
4. 密度口径：每阶段 main 4–6 条、context ≥8 条、critical ≥2 条；
5. birth-map 要素组合全覆盖（见 §三）；endings 含兜底结局（见 §四）；
6. 输出 `--count` 汇总（分母必须打印），供 README 数字对账（文档数字漂移防线）。

**事件密度口径**（阶段 × 类型矩阵，实际总数 M4 末态回填 00 台账）：

| 阶段 | 年龄段 | main | context | critical |
|---|---|---|---|---|
| 婴儿 infant | 0–3 | 4–6 | ≥8 | ≥2（由"家庭"代选，文案呈现被动性） |
| 幼儿 toddler | 4–6 | 4–6 | ≥8 | ≥2 |
| 童年 childhood | 7–12 | 4–6 | ≥8 | ≥2 |
| 少年 teen | 13–18 | 4–6 | ≥8 | ≥2 |
| 青年 youth | 19–30 | 4–6 | ≥8 | ≥2 |
| 壮年 adult | 31–45 | 4–6 | ≥8 | ≥2 |
| 中年 midlife | 46–60 | 4–6 | ≥8 | ≥2 |
| 老年 elder | 61–90+ | 4–6 | ≥8 | ≥2（含终局抉择） |

## 三、出生环境映射（`src/data/birth-map.json`）

开局四要素 → 初始四维（每维给出初始值或修正量，映射规则唯一存放于此）：

| 要素 | 枚举 |
|---|---|
| 年代 | 60s / 70s / 80s / 90s / 00s / 10s |
| 城乡 | 大城 / 小城 / 县镇 / 农村 |
| 家庭氛围 | 和睦 / 紧张 / 疏离 / 单亲 |
| 教养方式 | 权威 / 宽容 / 忽视 |

校验：四要素笛卡尔积（6×4×4×3 = 288 组合）**全部**有唯一初始四维解——实现为分层映射表（要素×维度各一行），validate 查覆盖完整性。

合成口径：初始值 = 中立值 50 + 四要素修正量之和；288 个组合的合成结果必须全部落域 [0, 100]（越界 = birth-map 设计错误，validate 拦截；引擎不对初始值做钳制）。

## 四、结局表（`src/data/endings.json`）

- 条件 = 终局四维区间（每维一个 [low, high]）+ 必含 flags + 禁含 flags；
- **≥ 8 个结局 + 1 个兜底结局**（全条件不满足时必中，防无可判）；
- 按列表序首个命中生效（顺序即优先级，引擎不另设规则）；
- 每结局：`title` / `typeText`（终局 MBTI 字母）/ `text`（人格画像与人生总结，原创）/ 复盘要点。

## 五、MBTI 画像文案

16 型 × 一段画像（各 80–150 字，原创），存放 `src/data/portraits.json`；字母→画像的映射为封闭枚举，validate 查 16 型齐全。

## 六、存档 schema（版本化，破坏性改动必须 v+1 并带迁移函数）

```jsonc
{
  "v": 1,
  "seed": 1730012345,          // 本次人生 RNG 种子
  "env": { "era": "90s", "place": "小城", "mood": "和睦", "style": "权威" },
  "stageIndex": 3,
  "dims": { "ei": 62, "sn": 41, "tf": 55, "jp": 48 },
  "history": [                 // 已决事件与选择（驱动阶段小结与终局复盘）
    { "eventId": "infant-003", "option": 1, "dimsAfter": { } }
  ],
  "flags": ["rebel"]
}
```

- localStorage key：`xinlu.save.v1`（v 变更则 key 同步变，旧 key 迁移后清理）；
- 损坏兜底：解析失败 → 提示并保留"重新开始"路径，**绝不静默清档**；
- 无任何数据上传。

## 七、数据溯源与合成纪律

- 全部事件/画像/结局文案**原创**，`data/README.md`（M0 建）记录口径来源与查证三态（MBTI 维度定义 ⬜ 待核对）；
- 不引入真实人物、真实品牌事件；涉及时代背景只做氛围级描写；
- 禁止"同一套内容换标签充数"——各阶段文案独立创作，复用句式不超单阶段 1/3（validate 可加重复度抽查）。
