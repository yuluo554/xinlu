# 01 · 《心路》v2.0 题目文档（十段式）

> **定位宣言**：《心路》2.0——同一份人生，长出形象。你的 MBTI 不再只是四个字母，而是一条会陪你做选择的大肥鱼：它随四维倾向值改变活跃、表情与所处的水域；通关那一刻，凝成一张可以带走晒的人格卡片。
>
> 为什么值得做：v1 检验证明引擎与内容已达标（67/67 测试、112 事件、结局判定可复现），市面对比证明这一品类的传播公式是「可晒的社交货币 + 低门槛 + 梗文化」（依据与来源见 [../07-2.0优化方案.md](../07-2.0优化方案.md) §二、§八）。v2 补的正是缺的两块：**视觉人格化**与**可分享的终局资产**，顺带补齐已知平衡缺口。

## 一、介绍

v1.0.0 已发布（tag / Release / Pages 三件套齐，见 [../05-发布留档.md](../05-发布留档.md)），短板清单 S1–S6 与市面机会点分析见 plan/07 §一/§二。本轮为 v2.0 增量：不推翻 v1 任何口径（K1–K11 生效），在其上做「表现层升级 + 回归自动化 + 平衡修复」。

## 二、任务要求

**功能要求**（模块划分与 03-模块清单逐条收敛，共 **6 个模块**）：

1. **回归基线**——E2E 双端冒烟脚本（375/1280 一键通关）、assets/ 跟踪策略落地；
2. **人格鱼 avatar**——四维→形态参数纯函数、常驻 mascot、事件表情反馈；
3. **分享卡**——终局 Canvas 导出 1080×1440 PNG（鱼 + 雷达 + 型号 + 画像句 + 关键抉择 + 水印）；
4. **16 型图鉴**——本机累计通关史（独立存储 key），终局「未解锁型」提示；
5. **门禁与预算**——素材许可门、dist 体积预算门、credits 署名；
6. **内容平衡**——B1：补 T/P 侧语义事件，8 条件结局 + 兜底全可达。

**非功能要求**：零运行时依赖不破坏（K2）；存档 schema v1 不动（K6）；引擎五签名冻结（K11，v2 只走「新增导出」路线）；全部新增数值口径单源在 02；双端响应式不回退（375px 起步）。

## 三、提交材料

逐项路径与核对命令见 [00 §提交材料实物表](00-README总览.md)（唯一台账）。共 9 项：E2E 脚本、B1 事件与可达性扫描、avatar 模块与单测、分享卡模块、图鉴模块、credits、许可门/预算门脚本、v2 发布留档追加节。

## 六、边界与非目标

- 不做：账号/云存档/多语言/原生壳/内购广告（沿 v1）；不改四维口径与事件密度矩阵（K1）；不动引擎签名（K11）；
- PWA、音效、关键抉择回溯为 **P2 观察项**：默认不做，v2-M4' 前按证据拍板择项；
- 大肥鱼形象商用风险公开声明随 README 已知限制发布（措辞沿用 [assets/README.md](../../assets/README.md) 台账结论）。

## 十、已知限制（诚实公开，不许删）

1. 「大肥鱼/鲸鱼娘」是 DeepSeek 吉祥物的社区二创形象，公开分发的许可边界见 assets/README.md 台账；商用需自行评估，梗图原图与无证 GIF 原件永不分发；
2. 网络梗有时效性——avatar 机制与素材解耦（参数化），必要时可整体换皮为 CC-BY 素材；
3. B1 修复后仍不承诺 16 型的统计均衡（v1 已知限制 4 延续）；
4. 分享卡为客户端生成，不含任何用户数据上传（零埋点不变）；
5. E2E 依赖本机 IAB 工具链，其渲染节流等工具性伪影已在 HANDOFF-M7 §五记录，判读以同步 evaluate 结果为准。
