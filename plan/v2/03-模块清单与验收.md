# 03 · 《心路》v2.0 模块清单与验收

> 与 01 §二 逐条收敛：共 **6 个 v2 模块**。全部走「新增导出/新增文件」路线——不改 v1 冻结契约（K11：引擎五签名、viz `sanitize`、storage key 口径）。
> 状态枚举：⬜ 待 v2-Mx 实现 ｜ 🟡 进行中 ｜ ✅ 已验收（附验证记录）

## 1. 回归基线 `tests/e2e/` + assets 策略

- **职责**：`tests/e2e/smoke.mjs`——IAB 驱动 375/1280 两档、从开局到终局一键通关（同步 evaluate 连点），断言关键屏节点与终局类型非空；assets/ 跟踪策略落地（02 §八）。
- **验收**：`npm run e2e` 绿并纳入 v2 每棒出口门；故意断言改错一处必红（门禁自检留痕）。
- **依赖**：无（先行模块）。

## 2. 人格鱼 avatar `src/viz/fish.ts` + `src/data/fish-mood-map.json`

- **契约**：`createFishParams(dims)` 纯函数（02 §一参数表）+ `renderFish(params, el, past?)`（沿用 viz DOM 收窄面：createElementNS/setAttribute/sanitize）；mascot 接入卡片流（事件反馈）、阶段小结（转场）、终局（主视觉）；表情映射数据文件（02 §二）。
- **验收**：`fish.test.ts`（参数边界 0/50/100、确定性、NaN 回落、映射 19/19 覆盖）；E2E 渲染断言；**K 纪律：fish.ts 无 16 型字面量分支**（测试 grep 守护）。
- **依赖**：1（E2E 先行）。

## 3. 分享卡 `src/ui/share-card.ts`

- **契约**：布局计算纯函数 + Canvas 绘制分离（02 §四规格）；终局面新增「保存分享卡」按钮。
- **验收**：布局单测（canvas stub）+ 三端实存图留痕（docs/assets/）；导出文件名口径校验。
- **依赖**：2（鱼主视觉）、5（水印素材属白名单层）。

## 4. 16 型图鉴 `src/ui/gallery.ts`

- **契约**：读写 `xinlu.gallery.v2`（02 §三 schema）、图鉴屏（16 格 + 结局记录）、终局「未解锁型」提示；损坏视为空图鉴重建（刻意放宽语义，02 §三已记录理由）。
- **验收**：`gallery.test.ts`（读写、损坏重建、16 型封闭、endings 键 ⊆ 枚举）；UI 双端冒烟（E2E 补一段图鉴断言）。
- **依赖**：2（图鉴格用 avatar 缩略）。

## 5. 门禁与预算 `tools/check-assets-license.mjs` + `tools/check-dist-budget.mjs` + credits

- **职责**：许可门（02 §六判据：白名单 ⊆、credits 署名 3 行齐）；预算门（02 §七判据：gzip ≤500KB、单 WebP ≤50KB）；`public/credits.md` 署名文件。
- **验收**：两脚本变异自检（改坏必红→复原绿）留痕；纳入 v2-M3' 起的出口门与 CI（layout job 旁路可选）。
- **依赖**：无（素材入库前必须就位——**排序约束：先有许可门，再入 fish/ 素材**）。

## 6. 内容平衡（B1）`src/data/events.json` + `scripts/check-ending-reachability.mjs`

- **职责**：补 T/P 侧语义事件（守 v1 密度矩阵与 |Δ| 口径），使 end-04/05/07/08 线性策略可达；扫描脚本（02 §五口径）。
- **验收**：`npm run validate` 0 FAIL（含 02 §二新增映射校验）；扫描 0 退出码；防回退测试同行交付（删补齐事件扫描必红）；≥2 局不同出生环境实玩通关留痕（dogfooding）。
- **依赖**：无（与 1 并行可）。
