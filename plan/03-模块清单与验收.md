# 03 · 模块清单与验收

> 与 [01 §二](01-题目文档.md) 的功能模块**逐条收敛：共 6 个模块**。每模块给出职责边界、对外契约（函数签名即契约，实现不得越界改签名——改签名 = 跨模块变更，须同步本档与测试）。
> 状态枚举：⬜ 待 Mx 实现 ｜ 🟡 进行中 ｜ ✅ 已验收（附验证记录）

## 1. 数据与口径 `src/data/` + `scripts/validate-data.mjs`

- **职责**：事件库 / birth-map / endings / portraits 全部 JSON；schema 与口径见 [02](02-数据与口径.md)；数据只读、无逻辑。
- **验收**：`npm run validate` 0 FAIL；故意造错一处必红（门禁自检留痕）；`--count` 输出带分母的汇总供 README 对账。
- **依赖**：无（被 2/4/5 消费）。

## 2. 演化引擎 `src/engine/`（纯函数，无 DOM、无存储依赖）

> **契约冻结（M2 出口，2026-10-24）**：以下签名即冻结态，此后改签名 = 跨模块变更，须回改本档与测试。

- **契约**：
  - `createRun(env, seed) → RunState`（birth-map 初始化 + 种子化 RNG；env 枚举越界或 seed 非有限数抛错）
  - `pickEvent(state) → Event | null`（阶段调度：main → context 随机（种子抽取）→ critical；`pre` 过滤；null = 本阶段事件已取尽，调用方应 advanceStage；终局态恒 null）
  - `applyChoice(state, optionIndex) → RunState`（deltas + 钳制 + flags + history 追加；待答事件由 pickEvent 重导出，选项越界抛错）
  - `advanceStage(state) → RunState`（推进 stageIndex；elder 推进后 stageIndex = 8 即终局，再推进抛错；阶段小结数据由 history.dimsAfter + dims 派生，不新增存档字段）
  - `resolveEnding(state) → Ending`（endings 顺序判定）
  - 同 `seed` + 同选项序列 ⇒ 全程状态逐字段全等（**可复现契约**；种子抽取为无状态原语 `seededDraw(seed, 已决事件数)`，存档 schema v1 无需 RNG 字段）。
  - 另导出字母判定 `mbtiLetters(dims, env) → string`（兜底结局无 `typeText`，终局字母由四维实算，落点在此；`=50` 的裁定分支见 plan/02 §一）。
  - M3 附件导出（只读访问器，2026-10-24 实装；不改动上述冻结五签名）：`birthEnvOptions() → Record<要素, string[]>`（开局屏枚举唯一来源，UI 不得内联）；`initialDimsOf(env) → Dims`（阶段淡影与曲线起点）；`eventById(id) → Event | undefined`（history 无阶段字段，阶段聚合与关键抉择回顾由此反查）。
- **验收**：vitest 覆盖全部纯函数：偏移/钳制边界（0/50/100）、flag 死锁防护、结局顺序与兜底、可复现双跑全等；**防回退自检：回滚钳制逻辑对应测试必红**（M2 已留痕：钳制回滚 2 测试红、抽取退化 1 测试红，复原字节级一致）。
- **依赖**：1。

## 3. 存档 `src/storage/`

- **契约**：`load() → RunState | null`、`save(state)`、`clear()`；schema `v` 校验与迁移；损坏 → 返回 `null` 并上报 UI 提示，**绝不静默清档**。M3 附件导出 `hasSaveKey() → boolean`（key 在位即 true，UI 据此区分「无档」与「有档但损坏」）。
- **验收**：vitest（内存 localStorage stub）：正常读写、旧版本迁移、损坏输入走兜底路径；刷新页面续局（手动冒烟）。
- **依赖**：2（类型）；1（birth-map 枚举，仅作载入校验，不复写枚举清单）。

## 4. 视图 `src/ui/`（四屏）

- **契约**：开局屏（四要素选择 → `createRun`）→ 卡片流（`pickEvent`/`applyChoice`）→ 阶段小结（`advanceStage`）→ 终局报告（`resolveEnding`）；重开 = 清存档回开局屏。
- **验收**：M3 手动清单（375/768/1280px 三档 + 完整一周目通关截图留痕）；存档损坏提示可见；空态/重开不白屏。
- **依赖**：2、3、5。

## 5. 可视化 `src/viz/`

> **签名实装（M3，2026-10-24）**：`renderRadar(dims, el, past?)` 与 `renderCurve(history, el, initial?)`——契约双参形态不变，第三参为可选扩展（淡影 / 曲线起点），不破坏既有调用。

- **契约**：`renderRadar(dims, el)` 手绘 SVG（四轴 ei 上 / sn 右 / tf 下 / jp 左，值 0 在圆心 100 在外沿；`past` 可选历史淡影虚线多边形）；`renderCurve(history, el)` 四维演化曲线（x = 抉择序，`initial` 可选作 x=0 起点）。零第三方图表库；DOM 面只用 createElementNS / setAttribute / appendChild / textContent，值经 `sanitize` 消毒（非有限归中 50、越界钳制 [0,100]）。
- **验收**：冒烟测试断言终局面/小结面渲染出 `svg` 节点；值域越界数据不产生 NaN 属性（单测，2026-10-24 通过）。
- **依赖**：2（类型）。

## 6. 发布与门面 `README.md` / `DEVELOPMENT.md` / `CHANGELOG.md` / Pages

- **职责**：README 产品页（≤120 行，入口 ≤30 行，人格模型依据表，已知限制）；DEVELOPMENT.md 只做 `plan/` 索引不复制；构建与 Pages 部署；M6 三件套。
- **验收**：04 §M5 门清单逐项过；Pages URL 实开可玩；Release 五部分说明齐全。
- **依赖**：1–5 全部完成。
