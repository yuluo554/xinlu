# 02 · 《心路》v4.0 数据与口径（单一定义源）

> v4 新增口径**唯一事实源**（K1 延续）；v1（plan/02）/v2（v2/02）/v3（v3/02）口径继续生效，本档只做增量。实现与文案不得复写第二份表述。

## 一、出生年历法

- `birthYear`：整数 1955–2015；随机出生由种子派生，手选按 era 区间种子派生（▸M1''' 增补），自定义页签任选；
- `era` 转为派生展示（decade 归段：1955–1959 归 60s 段，2010–2015 归 10s 段）；
- 运行时年份：`runYear = birthYear + floor(ageMonths / 12)`；卡片徽章统一「**YYYY 年 · N 岁**」（N 沿 ageHint 口径）；种子复现契约扩展：同码 ⇒ 同 birthYear。

**▸ M1''' 增补（实现定稿口径，与实现同提交）**

- `eraOf(birthYear)` 归段表（era 出生年区间单源）：`60s=[1955,1969]`（1955–1959 折入）、`70s=[1970,1979]`、`80s=[1980,1989]`、`90s=[1990,1999]`、`00s=[2000,2009]`、`10s=[2010,2015]`（2016–2019 出生不在可选域，锚覆盖到 2030）。
- `eraMidYear` 表（旧档迁移 birthYear 派生单源）：60s→1965 / 70s→1975 / 80s→1985 / 90s→1995 / 00s→2005 / 10s→2012。
- 徽章落位：事件卡与后果卡年份徽章 = `runYear(出生年, 该卡 ageMonths) 年 · ageHint 原文`；时代卡徽章 = `锚年 年 · (锚年−birthYear) 岁`。
- 随机出生 draw 序（同码契约的实现单源）：env 四要素 draw 0–3（沿 v3 不变）→ birthYear draw 4（era 区间内均匀）→ region/structure/parentsJob/wealth draw 5–8（§三 概率表）→ 家庭姓名 draw 10 起。手选页签 birthYear/profile 用同一 draw 序（4–8），家庭同 10 起。

## 二、年代事件库（`src/data/era-events.json`）

```jsonc
{ "id": "era-2003-sars", "year": 2003, "scope": "national",   // national | international
  "titleHint": "口罩那年的中考", "text": "……",
  "deltas3": { "worldview": 1, "values": 2 }, "resourceDeltas": { "mood": -4 },
  "stageFit": ["teen"], "checkStatus": "✅已核对|典型值" }    // 事实三态
```

- 主锚 **1955–2030 每年 1 条**（国际 ≤15%）；`stageFit` 限定适配阶段（不匹配则跳过该锚，不强行插入）；
- **注入规则**：命运线在月龄命中年份时插入「时代卡」；**每阶段 ≤2 条**；与 critical 事件至少错开 1 张卡；时代卡**无选项**，固定增量（\|Δ3\|≤2，\|res\|≤8），进 history 记录（`kind: "era"`）；
- 查证三态表（`docs/v4-era-facts.md`）：每锚一行「事件/年份/渠道/✅事实 或 典型值」；
- 校验（validate E 区）：年份连续无缺、scope 占比、增量口径、stageFit 枚举、查证表行数 = 主锚数。

**▸ M1''' 增补（实现定稿口径，与实现同提交）**

- 校验区字母落 **R 区**：v1 事件库已占 E 区（validate 输出字母属脚本约定，非数据口径本身）；R 区同时收口本棒家庭面数据（birth-map 六因素扩展覆盖 / names.json 姓名池 / npcs.json 家庭注册槽）。
- `checkStatus` 枚举：`✅已核对`（公共事实，年份/事件名可核）/ `典型值`（氛围级典型生活，不声称具体事实）；`待核` 仅过程态，M1''' 出口门禁（76 锚不得留待核）。
- 注入细则（`eraEventFor` 契约）：下一张命运线事件（pickEvent 结果）的 runYear 命中锚年，且当前阶段 ∈ 该锚 stageFit 时插卡；已入 history 的锚不重复；**本阶段已插满 2 张不再插**；下一张为 critical、或 history 末条为 critical 时让位（与重大抉择至少错开 1 张卡，双向）；锚年在 stageFit 不含当前阶段时跳过不追插。阶段归属反查：history 末段连续的（kind:"era" 条目或事件 stage=当前阶段）条目计为本阶段已插数。
- `applyEraCard`：增量只走既有通道（deltas3 → applyValues + 四维派生偏移；resourceDeltas → applyResources）；history 追加 `{ eventId: 锚 id, option: -1, dimsAfter, kind: "era" }`（option=-1 为「无选项」哨兵，仅 kind:"era" 合法）。
- 文案纪律补充：产品名/赛事名/制度名属公共文化事实可入文（奥运/春晚/高考/高铁/AI 助手等）；真实机构名与真人名不写（尼克松访华写作「美国总统访华」类）。

## 三、出生画像与家庭生成

**六因素**（自定义页签枚举，全组合派生唯一解）：

| 因素 | 枚举 |
|---|---|
| 出生年 | 1955–2015 |
| 南北地域 | 南方 / 北方 |
| 城乡 | 大城 / 小城 / 县镇 / 农村（沿 v1） |
| 家庭结构 | 独生 / 双孩 / 多孩 / 单亲 / 隔代 |
| 父母职业 | 工人 / 农民 / 个体 / 教师医生 / 公职 / 待岗 |
| 家境档次 | 拮据 / 一般 / 宽裕 |

- 与 v1 四要素合并为「出生画像」：随机 = 全派生；手选 = 旧四要素（其余因素按 era 概率派生并展示）；自定义 = 六因素全选；birth-map 扩展为六因素修正量表，覆盖校验升为新组合空间；
- **家庭生成器** `src/engine/family.ts`：`generateFamily(profile) → NPC[]`——父母 2（单亲 1）/ 祖辈 0–2（隔代结构必 2）/ 同辈 0–3（独生 0）；初始 bond/tag 由氛围×教养派生表单源；姓名池 `names.json`（南北分池，同局无重复）；
- 开局屏「查看我的家庭」入口 → 图谱页（复用 v3 renderRelations）；后天仅 bond/tag 演化。

**▸ M1''' 增补（实现定稿口径，与实现同提交）**

- **六因素 ↔ v1 四要素派生表**（自定义页签由六因素派生 env，全组合唯一解）：
  - structure → mood：独生→和睦 / 双孩→和睦 / 多孩→紧张 / 单亲→单亲 / 隔代→疏离；
  - style：家境 拮据→忽视 / 一般→宽容 / 宽裕→宽容；父母职业 教师医生或公职 → 权威（覆盖家境档）；
  - era = eraOf(birthYear)（§一表）。
- **手选页签派生概率表**（draw 4–8，seed 确定性）：birthYear 于 era 区间均匀；region 南北各半；structure：mood=单亲⇒单亲，否则按 era 权重（60s/70s：多孩 .60/双孩 .30/独生 .05/隔代 .05；80s–00s：独生 .70/双孩 .15/多孩 .10/隔代 .05；10s：独生 .50/双孩 .30/多孩 .15/隔代 .05）；parentsJob 按 place 权重（农村：农民 .60/工人 .10/个体 .15/教师医生 .05/公职 .05/待岗 .05；县镇：农民 .30/工人 .25/个体 .20/教师医生 .10/公职 .10/待岗 .05；小城：工人 .35/个体 .20/公职 .20/教师医生 .10/农民 .05/待岗 .10；大城：工人 .30/个体 .20/公职 .20/教师医生 .15/待岗 .15）且 era 60s/70s 无个体（折入工人）、待岗仅 90s/00s（否则折入工人）；wealth 按 parentsJob 权重（农民/待岗：拮据 .50/一般 .40/宽裕 .10；工人/个体：一般 .50/拮据 .25/宽裕 .25；教师医生/公职：一般 .50/宽裕 .35/拮据 .15）。
- **birth-map 新增四组修正量**（与 v1 四组同量级 ±1–2，数据落 `birth-map.json`）：region 南方{ei0,sn1,tf1,jp0}/北方{ei0,sn−1,tf−1,jp0}；structure 独生{ei1,sn0,tf1,jp−1}/双孩{ei0,sn1,tf0,jp1}/多孩{ei−2,sn1,tf0,jp2}/单亲{ei−1,sn1,tf1,jp1}/隔代{ei−1,sn1,tf−1,jp2}；parentsJob 工人{ei0,sn1,tf0,jp2}/农民{ei−1,sn2,tf0,jp1}/个体{ei2,sn0,tf1,jp−2}/教师医生{ei−1,sn0,tf−1,jp2}/公职{ei0,sn0,tf−1,jp1}/待岗{ei−1,sn0,tf1,jp−1}；wealth 拮据{ei−1,sn1,tf1,jp1}/一般{0,0,0,0}/宽裕{ei1,sn−1,tf−1,jp0}。覆盖校验升为 **8 因素全组合 51,840 组**（6era×4place×4mood×3style×2region×5structure×6job×3wealth）初始四维落域 [0,100]。
- **家庭生成细则**（`generateFamily(env, birthYear, profile, seed)`）：父母 2（单亲仅 mother）；祖辈 0–2（隔代必 2；非隔代按 draw 取 0/1/2，1 位=grandma、2 位=grandma+grandpa）；同辈：独生 0 / 双孩 1 / 多孩 draw 2–3 / 单亲与隔代 draw 0–2，槽位 sibling-1..3。姓名池 `names.json`：姓池 20 + 南北各男女名池；家庭姓一次 draw 定（父/祖/同辈随家庭姓，mother 与 grandma 随己姓另 draw）；同局全名不重复。
- **初始 bond 派生表**（mood×style，单源本表）：和睦 宽威忽 = 80/72/62；紧张 = 65/55/50；疏离 = 48/45/40；单亲 = 75/65/55（相依为命加成）。祖辈：隔代 75 / 在世 60。同辈 65。tag 由 tagOfBond(bond) 派生。
- **NPC 注册槽**（npcs.json 增量，line 全 fate）：grandma/grandpa（role 祖辈）、sibling-1..3（role 同辈）；`NpcState.name`（可选）为家庭 NPC 的本局姓名，渲染时覆盖注册名。图谱 fate 内环 >4 节点时改整圆均分（原上半弧口径仅适 ≤4）。

## 六、图标对象级口径

- icon-map 每条增 `objectKey`（所选物件/场景名，如 `radio` / `torii-gate` / `sewing-machine`）；
- 选图纪律：**文本核心物件 ⊆ objectKey**（抽验口径）；Game-Icons 检索不到贴切图 → 补采清单（CC0 小图）→ 仍无则**显式豁免**（`objectKey: null`，卡片不配图，宁缺毋滥）；
- 校验（validate I 区扩展）：objectKey 与图标文件名一致性；豁免条目单独计数（目标 ≤10%）。

## 七、阶段小结结构（v4 版）

1. 阶段主题头：年代区间 + 年龄段 + 阶段场景图（CC0，逐张对文案留痕）；
2. **三观三轴说明**：每轴一行「区间词（如『感应偏重』）+ 本阶段位移箭头（↑2）+ 一句独白」（接线 `monologues` 表，区间口径沿 v3/02 §二）；
3. 四维雷达淡影对比（沿 v3）；
4. 资源五档状态（§四口径）；
5. 关键抉择回顾（沿 v3）。

## 八、文本写实化口径（M1''' 主工程验收标尺）

- 每条事件必含：**年代锚** ≥1 处（物件/物价/流行语，具体到可感）；**地域感** ≥1 处（南北/城乡差异句）；**家境感** ≥1 处（与家境档位呼应的细节）；**五感细节** ≥2 处；
- 字数门槛：critical ≥180 字 / context ≥100 字；
- **支线互引**：每条支线事件对主线或其他支线（NPC 或前事件）回指 ≥1 处；
- 初筛脚本（`scripts/check-story-quality.mjs`）：字数/互引计数/年代词表命中/五感词表命中四项机检；人工复核按批抽查 ≥30% 样本，**合格率 ≥90%** 出口（不合格条目清单进 backlog）；
- 纪律：真实机构/人名不写；物价用「典型值」标记（查证表两态）。

## 九、存档 schema v3（`xinlu.save.v3`）

```jsonc
{ "v": 3, "seedCode": "XL-…", "birthYear": 1987,
  "profile": { "region": "南方", "structure": "双孩", "parentsJob": "教师医生", "wealth": "一般", … },
  "env": {…}, "stageIndex": 3, "dims": {…}, "values3": {…}, "resources": {…},
  "lines": {…}, "npcs": [ …含出生家庭… ], "history": [ …含 kind:"era" 时代卡… ], "flags": […] }
```

- 迁移：v1→v3 / v2→v3（birthYear 派生、profile 补派生、家庭生成补齐、history 不回填时代卡）；迁移局打「历法迁移」标记（终局提示一句）；**绝不静默清档**（K6 语义）；图鉴 `xinlu.gallery.v2` 不动。

**▸ M1''' 增补（实现定稿口径，与实现同提交）**

- v3 键集：v2 十二键 + `birthYear`（整数 1955–2015）+ `profile`（region/structure/parentsJob/wealth 四键）+ 可选 `migrated`（bool，历法迁移标记）；history 条目可选 `kind:"era"`（此时 `option:-1` 哨兵，其余条目 option ≥0）；npcs 条目可选 `name`（非空串，家庭 NPC 本局姓名）。
- v2→v3 迁移：birthYear = eraMidYear(env.era)（§一表）；profile = 手选派生概率表（§三）按存档 seed 复算；家庭按现行口径补生成（既有 NPC 的 bond/tag 保留不覆盖，只补缺失成员）；migrated = true；写 v3 成功后清 v2 key（失败保原档，内存续玩）。v1→v3 走既有 v1→v2 链再 v2→v3。
- 时代卡 history 条目不参与「关键抉择」回看与阶段抉择计数（kind:"era" 前置过滤）。

## 十、E2E 与门禁增量

- E2E 断言新增：年份徽章推进（首卡年份 = birthYear + 首事件岁）、开局图谱节点 = 生成器输出、主题切换、五档词、小结三观呈现、自定义页签全流程；
- validate 新区：E（era）/ I 扩展（objectKey）/ birth-map 新组合覆盖；`check-story-quality.mjs` 入 `npm run validate:story`（分批开启）；
- 可达性：时代卡增量纳入扫描（年代轴抽样 6 组复跑），结论变化走双层版本规则。
