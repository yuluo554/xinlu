# 02 · 《心路》v3.0 数据与口径（单一定义源）

> v3 新增口径**唯一事实源**（K1 延续）；v1 口径（plan/02）与 v2 增量（plan/v2/02）继续生效，本档只做增量。引擎/前端/测试/数据不得复写第二份表述。
> 「▸ M1'' 增补」条目 = 2026-10-24 v3-M1'' 实现当日定稿的细化口径（套件首提交前落定，与实现同提交）。

## 一、年龄单调键

- 每事件新增 `ageMonths`（整数月龄，0–1200）；`ageHint` 文案保留展示；
- 调度口径：阶段内事件按 `ageMonths` **严格不减**；fate 主线定锚点，context 在相邻锚点月龄窗口内抽取；
- 数据门新增：阶段内单调校验（乱序即 FAIL）+ E2E 全程年龄不回退断言。
- ▸ **M1'' 增补（解析与单调判定）**：
  - `ageMonths` 必须与 `ageHint` 机判全等；hint 可解析格式 = `N个月` / `N岁` / `N岁半` / `N岁M个月`（`N岁半` = 12N+6，`N岁M个月` = 12N+M）；
  - 阶段内单调规则：① main 事件按**库序** `ageMonths` 不减（主线定锚即库序即锚序）；② 全部 critical（含支线）在普通事件之后出牌，最低月龄 critical ≥ 本阶段非 critical 事件最大值；critical 之间按月龄出牌（同月龄按库序，stable sort——支线 critical 月龄可早于 fate 收束锚点）；③ 相邻阶段 max(stage k) ≤ min(stage k+1)（跨阶段全程不回退）；非 main 事件允许早于首个 main 锚点（开卷窗口，调度器先抽干更早月龄档）——不设下界约束；
  - 调度器窗口抽取（引擎实现口径）：下一个 main 锚点之前，先抽干 `ageMonths ≤ 锚点月龄` 的非 main 候选（同月龄为一档，档内随机）；全部 main 消费完后按同档规则抽干剩余非 main，最后按库序出 critical。同档内随机 + 档间按月龄 → 任意抽取序列天然不减。

## 二、三观中间层

- 三轴 [0,100] 整数：**世界观** `worldview`（理性 0 ↔ 感应 100）、**人生观** `outlook`（进取 0 ↔ 安然 100）、**价值观** `values`（原则 0 ↔ 共情 100），初始 50；
- **传导链**：选项 → `deltas3`（三观主效应，|Δ| 常规 ≤3 / critical ≤8，沿 v2 偏移口径）→ `deriveDims(values3, dims, line)` 纯函数派生四维偏移（派生系数表单源本档：worldview→sn、outlook→ei/jp、values→tf，每轴系数 0.4，方向按增量符号）；**旧 `deltas` 四维直改字段从事件 schema 移除**；
- **非选项漂移**：每阶段小结时按 `stageDrift`（数据文件表，每阶段 ≤2/轴）轻推三观（他人/时代影响）；
- 表现：三观数值不直接示人；阶段小结「内心独白」按各轴区间（<35 / 35–65 / >65）选文案（文案表单源 portraits 旁新文件）。
- ▸ **M1'' 增补（传导实现口径）**：
  - 派生偏移**逐轴方向表**（方向按增量符号的具体指向）：worldview `+δ`（向感应）→ `sn +round(0.4δ)`（向 S）；outlook `+δ`（向安然）→ `ei −round(0.4δ)`（向 I）、`jp −round(0.4δ)`（向 P）；values `+δ`（向共情）→ `tf +round(0.4δ)`（向 F）。`round` 为四舍五入（0.4×整数 δ 的小数部 ∈ {0,.2,.4,.6,.8}，无 .5 边界）；`round(0.4×±1) = 0` = 纯三观微动不动性格，属设计内（性格是慢变量）；
  - 传导核 = `dimsOffsetOf(deltas3)`（以增量为输入，上表唯一实现）；`deriveDims(values3, dims, line)` 为**同表的状态级投影**：以 `values3 − 50`（中性基）过同一方向表得「当前三观隐含的性格倾向」，并把各维输出钳在本维剩余空间内（不越极点）。前者服务逐选项传导，后者服务画像/隐线展示；两函数共享同一张方向表（三方核对表以此为锚）；
  - `line` 形参在 v3-M1'' 为预留位（全线恒等影响，零调制）；线别调制如后续需要，系数表先入本档再改实现；
  - 存量 121 条换算口径（原 `deltas` → `deltas3` 反推）：`axis = symRound(原delta / 0.4)`（symRound = 远离零取整）后按 3（critical 8）钳制；ei/jp 同轴（outlook）冲突时取原 |delta| 大者、平手取 ei——换算是**方向保持的有损重写**（原四维直改字段从 schema 移除，原量级经 0.4 系数自然放缓，方向逐维保真为主判据）；
  - 独白文案表落 `src/data/monologues.json`（3 轴 × 3 区间），漂移表落 `src/data/stage-drift.json`（8 阶段 × 3 轴，|值| ≤2 整数）。

## 三、轻量资源（游戏感张力源）

- 3 项 [0,100] 整数：**心境** `mood`、**积蓄** `money`、**健康** `health`，初始 60；
- 事件选项携带 `resourceDeltas`（常规 |Δ| ≤10 / critical ≤25）；每阶段结束自然结算（心境 −5 漂移、健康随年龄段递减、积蓄随 career 线结算——系数表单源本档）；
- **低值分支**：<25 触发该资源救助事件（每资源 2 条，入库 schema 新 `type: rescue`）；=0 时锁定部分支线选项（`requires` 字段校验）；
- 表现：状态条常驻（图标+数值，无进度条堆砌），增损时数值浮动动效（game-feel 反馈预算内）。
- ▸ **M1'' 增补（结算系数表 / rescue / requires 实现口径）**：
  - 每选项 `resourceDeltas` 必填（键 mood/money/health，整数，≥1 项非零，零偏移删键）；rescue 事件选项的资源上限同 critical（25），三观上限仍 3；
  - 阶段末自然结算（`advanceStage` 离开该阶段时一次性结算）：`mood −5`；`health −h(stage)`，h = {infant:0, toddler:0, childhood:0, teen:0, youth:1, adult:2, midlife:4, elder:6}；`money +m(lines.career)`，m = `floor(lines.career / 20) − 4`（career 0→−4 生活成本，80 以上收支转正）；
  - rescue 触发 = 结算/选项增损后该资源 `< 25` 时该阶段池内**未消费**的同资源 rescue 事件进入抽取候选（不作插队，按月龄档参与单调抽取）；资源 ≥25 时 rescue 事件不可见；
  - `requires`：`Partial<Record<ResKey, number>>`，语义 = 所列资源各 **≥ 阈值**该选项才可选（引擎 applyChoice 拒绝 + UI 禁用置灰）；阈值整数 ∈ [1,100]；锁定只用于支线选项（fate 事件不使用）；M1'' 首批用法 = 金钱门槛类选项（requires money ≥ 20 一档）；
  - 数值边界：三观/资源/线进度全部整数，钳制 [0,100]。

## 四、多线系统

- `line` 枚举：`fate`（命运主线，含现 main/critical）/ `study` / `career` / `love` / `friend` / `health`；
- 调度：每阶段 = fate 必经（4–6）+ 各支线轮转 ≥3（**分批口径**：M1'' 交付 study+career，M2'' 补 love+friend，M3'' 补 health；密度门按线分批开启，M4'' 全开）；
- 线进度：每线 0–100 隐性进度（选择推进），关键阈值解锁该线 critical（升学/跳槽/表白等）；
- 结局判定 v3 输入：终局四维 + flags + **线终态**（每线终态枚举：圆满/平顺/中断/未启）+ 三观画像。
- ▸ **M1'' 增补（线进度 / 线终态阈值）**：
  - 选择任一支线事件（line ≠ fate）的任意选项 → 该线进度 `+lineGain`；`lineGain` 事件级可选字段，缺省按类型：context 8 / critical 15；rescue 恒 0；fate 无进度；
  - 支线 critical 解锁阈值 = 该线进度 **≥ 60**（未达阈值该 critical 不入候选池，不占密度分母——密度门数池内事件，不数单局消费量）；
  - 线终态映射（终局时按该线进度）：0 = **未启**；1–29 = **中断**；30–79 = **平顺**；≥80 = **圆满**；
  - `deriveEndingV3(state)`（M1'' 交付）：结局**选择**仍沿 v2 四维+flags（endings.json 不动），v3 增量 = 在其上附线终态与三观画像的结构化输出；线终态参与结局**判定**随 M3''/M4'' endings 口径扩展再启用。

## 五、NPC 与关系图谱

- NPC：`{ id, name, role(父母/师/友/上司/同事/伴侣/子女/医生…), bond[0,100], tag(亲密/疏离/决裂/羁绊) }`；父母初始在册；
- 关系事件：支线事件选项可带 `bondDeltas`（|Δ| ≤15）；`values` 轴影响增益衰减（系数 0.5 单源本档）；
- 图谱布局：环形固定布局（父母内环、线别 NPC 外环按线分区），连线宽度 = bond 映射 [1,6]px，颜色按 tag；零依赖手绘 SVG；
- 终局报告收录图谱快照（SVG 序列化）。

## 六、随机出生与种子码

- 开局「随机出生」：`seedCode = XL-XXXX-XXXX`（Crockford Base32 去 易混字符），种子派生四要素 + 后续 RNG；
- 输入种子码 → 完全复现同一段人生（离线契约）；手选出生 = 沿 v2 路径（种子仍生成并显示）。

## 七、LLM 旁路（D2=a）

- 设置页开关 + BYO Key（localStorage 存 Key，明文提示风险）；服务商下拉（OpenAI 兼容协议，Base URL 可配）；
- 三个用途：①自定义选项裁决（自由文本 → 归一为 {文案, deltas3, resourceDeltas, bondDeltas}——**换算用本地规则表，LLM 只产叙事与建议标签**）②context 事件变体改写（原文语义保持，deltas 不变）③终局人生点评一段；
- **过网隔离**：判定核心（engine/ 目录）禁止出现 fetch/XMLHttpRequest（以测试 grep 守护）；LLM 调用全部在 `src/llm/` 单层；
- 降级：无 Key / 关开关 / 超时（8s）/ 报错 → 自定义槽隐藏、事件用原文、点评用预设文案；离线态行为与 v2 完全一致；
- 自定义槽口径：每事件第 4 槽，开关开启且 Key 有效时显示；LLM 返回的 deltas3/resourceDeltas 走本地钳制后才入状态。

## 八、存档 schema v2（`xinlu.save.v2`）

```jsonc
{ "v": 2, "seedCode": "XL-7Q3K-9M2D", "env": {…}, "stageIndex": 3,
  "dims": {…}, "values3": { "worldview": 50, "outlook": 50, "values": 50 },
  "resources": { "mood": 60, "money": 60, "health": 60 },
  "lines": { "study": 30, "career": 0, "love": 10, "friend": 20, "health": 40 },
  "npcs": [{ "id": "mother", "bond": 70, "tag": "亲密" }],
  "history": […], "flags": […] }
```

- 迁移：v1 档 → v2（values3/resources 补初始中位、lines 补 0、npcs 补父母默认），v2 档不存在的场景不适用；迁移单测覆盖 v1/v2 两种旧档；**绝不静默清档**（沿 K6 语义）；
- 图鉴 key `xinlu.gallery.v2` 不动。
- ▸ **M1'' 增补（信封字段分期）**：`seedCode` 文本码随 v3-M3'' 种子码功能加入信封（新增可选字段，读取缺省按 `seed` 数值键工作）；M1'' 信封以 `seed`（数值）承载可复现契约，顶层键 = `v/seed/env/stageIndex/dims/values3/resources/lines/npcs/history/flags`。v1 档迁入 v2 成功写新 key 后清理旧 `xinlu.save.v1` key（沿 storage 迁移链注释口径）；NPC 父母默认 = `{id:"mother", bond:70, tag:"亲密"} / {id:"father", bond:70, tag:"亲密"}`。

## 九、素材口径（D3）

- 事件图标层：Game-Icons（CC-BY 3.0），每事件 1 枚主题图标，**逐张对文案清单**（图标名↔事件 id 对照表入库）；
- 场景底图/纹理：CC0 优先（OpenGameArt/公版纹理，检索式与下载留痕入 assets/README.md 增量节）；
- 大肥鱼素材降级彩蛋层（抉择反馈表情保留）；新素材全部过许可门白名单（v2 tools/check-assets-license.mjs 扩展）+ 预算门（gzip ≤500KB 重审，超限先压缩）。
- ▸ **M2'' 增补（预算线重审）**：v3 预算线定为 **gzip ≤650KB**（原 500KB 为 v2 素材面口径）。重审依据：175 枚 Game-Icons 事件图标层（gz 约 130–150KB）是 D3 拍板的叙事美术主体，为保住 v2 既有画质不动（分享卡鱼主视觉以 330px 绘制、鱼帧源维持 192px——压缩>减帧>降分辨率纪律优先保用户可见面），预算线按 dist 构成实算抬升：v2 基线 475KB + 图标层 + CC0 纹理 ≤20KB ≈ 630–650KB；门脚本 `tools/check-dist-budget.mjs` 阈值同步（注释引本节）。对照表单源 = `src/data/icon-map.json`，逐张对文案清单 = `docs/v3-M2-icons.md`。

## 十、LLM 与数据门的边界

LLM 动态产出不进数据门覆盖口径（无静态真值）；人审抽检留痕（每里程碑 ≥10 条）入 docs/。
