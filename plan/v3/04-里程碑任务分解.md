```
→ 留档「tag 后追加」分栏 → 状态副本/台账翻齐 → HANDOFF-v3-M5 收官
```

**出口门**：三件套；README 增量（时间轴/图谱/LLM 说明+开关提示）不破行数门；全部门绿。

## 风险与恢复

| 风险 | 对策 |
|---|---|
| 121 条事件逐条补键/换算/扩写工作量大且易错 | 换算用系数表脚本辅助+人工复核；validate 新门兜底；本棒不分叉其他工作 |
| 三观传导「间接化」削弱掌控感（08 §八） | 独白明示偏向 + dogfooding 双盲调参 + 系数表单源可调 |
| Game-Icons 图标与文案对不上 | 对照表先行（2.1 先表后图），对不上的事件改用场景底图表达，不强配 |
| LLM 依赖破坏可复现/离线 | 过网隔离 grep + 降级三路径测试 + 判定核心零改动（K11） |
| 预算门被新素材撑爆 | 2.1 采集即压缩；预算门红即裁（压缩>减帧>降分辨率） |
| 老档迁移丢失 | 迁移单测双旧档覆盖；损坏提示不清档纪律延续 |
