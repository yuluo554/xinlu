# 01 · 《心路》v3.0 题目文档（十段式）

> **定位宣言**：《心路》3.0——选择先改变三观，三观再长成性格。学业、事业、爱情、友情、健康各有各的路，身边人各有各的走向；开局可以抽签，一段种子决定一种人生；你也可以写下自己的活法。一条时间轴，走完一生。
>
> 为什么值得做：v2 实玩实测（08 §〇·二 18 条发现）证明机制与内容达标但**游戏感缺席**——无目标张力、无即时反馈、无成长可视化。v3 用「三观中间层 + 多线 + 资源张力 + 时间轴界面 + 叙事美术」把翻页器变成游戏。

## 一、介绍

v2.0.0 已发布（三件套齐）。用户实玩反馈九条 + 代理实测新增九条（共 18 条，全文见 [../08-3.0优化方案.md](../08-3.0优化方案.md) §〇/§〇·二），收敛为四类改造：**机制层**（年龄单调缺陷修复、三观中间层、多线、资源、随机种子、选项扩展）、**表现层**（时间轴界面 D4=B、无版权叙事美术 D3、动效按 game-feel-and-juice 纪律）、**辅助系统**（关系图谱、LLM 旁路 D2=a、声音择项）、**发布**（v3.0.0 主版本）。

## 二、任务要求

**功能要求**（与 [03-模块清单](03-模块清单与验收.md) 逐条收敛，共 **6 个模块**）：

1. **引擎 v3**——年龄单调调度、三观传导层、多线调度、轻量资源、随机种子派生出生、结局判定 v3；
2. **数据与文本**——存量 121 条事件补 `ageMonths`/`line`/`resourceDeltas`/第三选项，扩写至多线密度口径，新增支线事件；
3. **界面重构**——时间轴画卷布局（D4=B）、叙事美术（D3）、状态条、抉择重量分级、动效（game-feel CHECKLIST）；
4. **关系图谱**——NPC 模型、关系事件、图谱页与终局收录；
5. **LLM 旁路**——设置开关 + BYO Key、自定义选项裁决、事件变体、终局点评、离线降级；
6. **门禁与发布**——许可门白名单扩展、单调门/密度门收紧、v3.0.0 三件套。

**非功能要求**：零运行时依赖不破坏；引擎判定核心**永不过网**（LLM 仅文案旁路）；离线态行为与 v2 完全一致；存档 schema v2 迁移不清档；双端响应式。

## 六、边界与非目标

- 不做：账号/云存档/多语言/原生壳/内购广告；不做实时联网对战等任何联网玩法（LLM 旁路是唯一过网点，且可关）；
- LLM 不参与判定：三观/四维/结局计算永不过网，可复现契约在离线态完整保留；
- 支线交付分批：M1'' 先 study/career，love/friend/health 随 M2''/M3'' 补齐（密度门按线分批开启）；
- 声音为 M3'' 择项（CC0 音效，默认轻量 3–5 个）。

## 十、已知限制（诚实公开，不许删）

1. LLM 开启后事件上下文会发送至用户所选服务商（设置页明示）；离线态与 v2 行为一致；
2. LLM 生成文案不计入数据门覆盖口径（动态内容无静态真值），仅人审抽检；
3. 三观传导系数首版为设计值，可感度依赖 dogfooding 调参；
4. 支线分批交付，M1'' 出口时 love/friend/health 线密度未达标属计划内（分批口径见 02 §四）；
5. 老存档迁移补中位三观/资源，迁移局的三观画像从迁移点起算（不回溯）。
