# 01 · 题目文档（十段式）

> **定位宣言**：《心路》是一款界面清爽、双端即开即玩的网页人生模拟——你从一段出生环境开始，看着 E-I / S-N / T-F / J-P 四维倾向值慢慢长成人格；每一次抉择都在雷达图上留下轨迹，终局凝结成一份可分享的人格演化报告。
>
> 为什么是"游戏"而不是"AI 聊天"：人格的**连续演化与全程可视化**是可复现、可回放的确定性引擎（种子化 RNG），不是对话即兴生成；离开这一引擎，「看着自己的人格被塑形」的体验不成立。

## 一、介绍

人生重开模拟器类产品证明了「快速过完一段人生」的传播力（同类现状 ✅ 已核对（2026-10-24）：检索快照见 [data/README.md](../data/README.md) 依据查证表）。但现有产品大多止于事件罗列与属性加减，**没有人格的形成与演变**这条主线。本作把「环境塑造人格、选择改变人格」做成连续演化的确定性引擎与全程可视化轨迹——这是本作的差异化主张（开源空白属软论据，仅作辅助，不作硬锚点；检索式与日期快照于 M1 前回填）。

## 二、任务要求

**功能要求**（模块划分与 [03-模块清单](03-模块清单与验收.md) 逐条收敛，共 **6 个模块**）：

1. **数据与口径**——8 阶段事件库、出生环境映射（birth-map）、结局表（endings），全部 JSON 数据驱动 + 校验脚本；
2. **演化引擎**——种子化 RNG、阶段状态机、四维偏移（含钳制）、结局判定的纯函数集合；
3. **存档**——localStorage 读写、schema 版本化与迁移、清除与损坏兜底；
4. **视图**——开局（环境四要素）、卡片流（阶段+事件+选项）、阶段小结、终局报告 四屏；
5. **可视化**——手绘 SVG 雷达图与演化曲线，无第三方图表库；
6. **发布与门面**——构建、GitHub Pages 部署、README 产品页、CHANGELOG。

**非功能要求**：双端响应式（≥360px 手机 → 桌面宽屏）；零运行时依赖；无网络也能玩（单机、无埋点、不采集数据）；同种子同选项序列结果可复现。

## 四、验收标准（每条可机械核验）

| # | 标准 | 核验方式 |
|---|---|---|
| 1 | 数据完整性 | `npm run validate` 0 FAIL（schema/密度/引用/口径全查）；**门禁自检：故意删一条事件或改坏一处 delta 必须报红** |
| 2 | 引擎正确性 | `npx vitest run` 全绿；**防回退自检：回滚任一钳制/判定逻辑，对应测试必须变红** |
| 3 | 可复现性 | 同 seed + 同选项序列跑两遍，终局四维值全等（脚本断言） |
| 4 | 双端可用 | 375 / 768 / 1280px 三档手动清单全过并留痕（M3） |
| 5 | 内容完整 | 每阶段事件密度达口径；≥8 结局可被实际触发；≥3 条不同出生环境全通关实玩留痕 |
| 6 | 发布达成 | M6 三件套（tag + Release 附产物 dist.zip+sha256 + plan/05 留档）；Release 说明五部分齐全 |

## 六、边界与非目标

- **非心理测评**：本作是文学化模拟，不构成任何心理测量或建议；MBTI 的信度争议列入「已知限制」公开声明；
- **v1 不做**：云存档/账号体系、分享图导出、多语言、事件 UGC 编辑器、原生 App 壳；
- **隐私**：单机运行、零埋点，存档仅存于玩家本机 localStorage；
- **双端定义**：响应式网页（手机/电脑浏览器），不含小程序与原生壳。

## 十、已知限制（诚实公开，不许删）

1. MBTI 本身在心理测量学界存在重测信度与效度争议，本作定位**娱乐向**，不构成心理测评；
2. 事件为文学化模拟，不代表真实人生发展规律；
3. 存档仅在本机 localStorage，清浏览器数据即丢失（v1 不做云存档）；
4. 各 MBTI 路线的可达性与平衡依赖实玩调参，v1 不承诺统计意义上的均衡；
5. 本机网络直连 GitHub 受限，发布动作依赖镜像/代理通道（对策见 04 §风险）。
