## 一、v2.0.0 基线（不推翻的部分）

引擎五签名、种子可复现、121 事件数据门、E2E 双端、四道门禁、双端响应式——全部保留。v3 是**状态层扩展 + 表现层重构**，不是重写。

## 二、3.0 定位宣言（草案）

「《心路》3.0——选择先改变三观，三观再长成性格。学业、爱情、事业各有各的路，身边人各有各的走向；开局可以是抽签的一段人生，你也可以写下自己的活法。」

## 三、机制重设计（v3 核心）

### 3.1 随机出生 + 种子码
- 开局新增「随机出生」：由种子派生四要素（现有种子化 RNG 直接复用），并显示**种子码**（如 `XL-XXXX-XXXX`）；输入种子码可复现同一段人生（同种子同人生的 v2 契约顺延到出生环节）；
- 手选出生环境保持不变，随机与手选并列。

### 3.2 年龄单调修复（发布物缺陷，v3-M1'' 第一块）
- 数据：每事件新增数值排序键 `ageMonths`（整月龄，ageHint 文案保留作展示）；存量 121 条事件逐条补键；
- 引擎：阶段内调度按 `ageMonths` 单调不回退（主线与 context 都纳入排序，context 在同月龄窗口内抽取）；
- 校验：数据门新增「阶段内 ageMonths 严格单调」规则 + E2E 断言全程年龄不回退；变异自检（改乱一条必红）。

### 3.3 三观中间层（「性格是三观的表现」）
- 新增**三观向量**（内隐层，3 轴 [0,100]）：**世界观**（理性 ↔ 感应）、**人生观**（进取 ↔ 安然）、**价值观**（原则 ↔ 共情）；
- 传导链改为两段：**选项 → 三观偏移（主效应）→ 四维偏移 = 纯函数 f(三观当前值, 三观增量, 线别)（派生效应）**——玩家不再「直接点性格」，而是活出三观，性格随之显形；
- 三观还会**非选项漂移**：阶段事件（他人影响、时代背景）按权重轻推三观——性格变化不全部来自选择，回应反馈 #5 的本义；
- 表现层：三观数值不直接示人，通过阶段小结「内心独白」文案（按三观区间选文案）与终局「三观画像」表达；雷达图旁新增三观隐线（可选显示）；
- 工程纪律：f 为新增纯函数导出（K11 路线），不改引擎五签名；三观入存档 schema v2（迁移函数 + 老档补中位值，绝不静默清档）。

### 3.4 多线系统（主线 + 支线）
- 事件新增 `line` 维度：`fate` 命运主线（现有 main/critical 并入）+ 支线 **study 学业 / career 事业 / love 爱情 / friend 友情 / health 健康**；
- 阶段调度 = 主线必经 + 支线轮转抽取（各线有独立隐性进度，推进到关键节点解锁该线重大抉择：升学/跳槽/表白/婚育等）；
- 线状态参与结局判定（endings 口径扩展：终局四维 + 关键 flag + **线终态**）；
- 密度口径升级：每阶段主线 4–6 + **每条支线 ≥3**（数值口径仍单源 plan/v3/02）。

### 3.5 人物关系图谱
- NPC 模型：父母为初始节点；学业线带来师/友、事业线带来上司/同事、爱情线带来伴侣、健康线带来医生……每个 NPC 有关系值 [0,100] 与标签（亲密/疏离/决裂/羁绊）；
- 关系事件：支线事件的选项可改变 NPC 关系值与标签（与三观联动：待人观影响关系增益衰减）；
- 图谱页：手绘 SVG（环形布局 + 连线粗细表关系值 + 标签着色，零依赖纪律延续），阶段小结可查看，**终局报告收录「一生的人际图谱」**；
- 存档 schema v2 携带 NPC 状态；迁移同 §3.3。

### 3.6 选项扩展：≥3 + 自定义
- 口径升级：每事件选项 **≥3**（现 2–4；存量 121 条逐条扩写，validate 口径同步收紧）；
- 第 4 槽固定为「**自定义**」：玩家自由输入想做的事 → **需要大模型接口裁决**（见 §六 D2）；未接 LLM 时自定义槽隐藏（口径写死，不留灰按钮）。

## 四、界面重构（回应 #1/#9，D4 决策幅度）

- **A 渐进（建议）**：换叙事插画体系（§五）+ 卡片信息层级重排（阶段徽章/线别标签/年龄徽标）+ 轻动效补齐 + 设计规范重跑（design-taste 纪律），布局骨架不动；
- **B 重设计**：时间轴式人生画卷布局（左侧时间轴 + 右侧事件卡）、双栏桌面态；工作量为 A 的 2–3 倍；
- 无论 A/B：**mascot 降级**——大肥鱼从「每屏站桩」改为三类出场（抉择反馈表情、阶段转场彩蛋、终局庆祝），不再承担叙事画面。

## 五、美术路线（回应 #2/#9，D3 决策三选一）

| 路线 | 内容 | 许可 | 成本 |
|---|---|---|---|
| **a 混合（建议）** | 事件**图标层**用 Game-Icons（4600+ 枚 CC-BY 主题图标：摇篮/书包/戒指/公文包……逐一贴合事件文本）+ **阶段场景底图** AI 生成（本地管线，项目已有先例）或 unDraw 插画 | CC-BY 署名 / 自产 | 中 |
| b 全 AI 生成 | 全部事件配图本地模型生成，风格统一 | 自产（风格参照需注意） | 高（生图+审图管线） |
| c 抽象极简 | 不用具象图，几何图形/色块表达阶段与线别 | 无 | 低（但与「不简陋」诉求有张力） |

- 选取纪律：所有新素材入库前**逐张对文案**（「这张图说的是不是这件事」），许可门白名单同步扩展；大肥鱼素材全部降级为彩蛋层，保留表情反馈用途。

## 六、LLM 接口（回应 #3，D2 决策三选一）

| 档 | 内容 | 代价 |
|---|---|---|
| **a 可选接入（建议）** | 设置页显式开关 + 用户自带 API Key（BYO）；用途：①自定义选项裁决 ②context 事件动态变体改写 ③终局人生点评。**未开启 = 完全离线，行为与 v2 一致**；开启 = 明示「将向所选服务商发送事件上下文」（零上传承诺按开关状态如实变更） | 打破绝对离线（用户显式选择）；需处理超时/失败降级到预设池 |
| b 本地小模型 | ollama 等本地推理，零云端 | 安装/硬件门槛，移动端基本不可用 |
| c 不接 LLM | 内容池扩容代替动态性（自定义槽永不上线） | 与用户「不可能每次都预设」诉求相悖 |

- 工程约束：LLM 为**可选旁路**——判定核心（三观/四维/结局）保持本地纯函数可复现，LLM 只产文案与裁决自由输入（自由输入的三观换算用本地规则表兜底），种子可复现契约在离线态完整保留；
- D2 未拍板前：v3 先行交付 §3.1–3.5 + §3.6 的 ≥3 选项部分，自定义槽与 LLM 相关项整体挂起。
