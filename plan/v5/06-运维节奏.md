## 节奏增量

- 周自查轮转扩为十六类；月迭代 ≤2 项不变；
- **配图回访**：每季度抽验 20 张配图与事件文本的贴合度（D9 纪律运维化）。**机检先行**：跑 `node tools/v5-scene-audit.mjs`，先修清单内的错配再谈抽验——v5-M5 首查实测 52 条（17.6%）图不对事，已入队 SI-001；
- **槽位/家谱回访**：外部反馈「称谓不对」按高优先级（家庭结构是可信度基石）；
- **跨端回访（沿用 v1 第 8 类，v5 面加重；v5-M6 补机检口径）**：v5 加了配图层与卡片三层后，375/1280 是最可能分叉的一类。**机检先行**：`npm run e2e`（双端各跑一键通关）——375 档硬断言 L1 行宽 ≤34 字、选项 2–3、单屏 ≤160、**事件卡内触控目标（`[data-option]` / `[data-continue]`）边长 ≥44px**（v5-M6 补：此前该口径只有 CSS token 与 `docs/M3-手动清单.md` 的目检项，**无自动断言**，CSS 一改就静默破）；机检绿后再读 19 张双端留痕截图**逐对比对**，判据 = 差异**只允许出现在布局档**（列数 / 纵排↔双栏 / 同构缩放），一旦出现**文字断行差异、元素溢出横滚、触控目标 <44px** 即入队。v5-M6 预跑实测：无漂移（图鉴 375 = 2 列 / 1280 = 4 列同为 16 格；图谱 375 纵排单列 / 1280 左图右表；关系网同构放大），触控最小边双端 **44px**；375 档首屏截断项（出生证明卡，机检坐实「内容底缘 = 视口末行」）另挂 [backlog](backlog.md) 观察区——**不许把「滚动」当成漂移判红**；
- **主题/偏好回访（v5-M2'''' 增量）**：主题键 `xinlu.theme.v1` 与阅读偏好键 `xinlu.prefs.v1` 独立于存档；改主题色板必须同跑 `theme-contrast.test.ts`（四款主题对比度 ≥7:1 / ≥4.5:1 逐条）；改字号档必须确认「只抬字号、不改行宽」（`card-layers.test.ts` 守）；
- 发版规则不变：文本长度口径或判定呈现变化 → 主版本 +1 + 重开声明。
