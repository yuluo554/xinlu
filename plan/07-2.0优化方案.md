## 二、市面同类产品对比与机会点

| 产品 | 形态 | 与《心路》的关系 | 可借鉴 / 可回避 |

| 人生重开模拟器 | 纯文字事件流，2021 年 3 天 2 亿访问 | 品类鼻祖，同为网页零门槛 | **借鉴**：可晒的「人生总结」截图 = 社交货币，是传播核心；梗文化内容。**回避**：事件罗列无主线人格演化 |

## 三、2.0 目标与非目标

- **一句话目标**：从「能玩的文字游戏」到「想晒的人格模拟体验」——人格长出形象（人格鱼）、终局可带走（分享卡）、平衡补齐（B1）、回归自动化（E2E）。

### 4.2 「人格鱼」avatar 系统（P0，v2 的灵魂设计）

**核心创意**：不把美术当贴纸，而是**让四维倾向值驱动一条鱼的形态**——你的 MBTI 就是你的大肥鱼。

| 维度 | 驱动的表现参数 | 用到的现有素材 |
|---|---|---|
| E-I | 活跃度：idle 动画速度/位移幅度（E 高速巡游，I 沉底静卧） | `fatfish-idle-0..5` 六帧 |
| S-N | 氛围层：水域色彩与背景鱼群密度（S 清淡写实，N 幻彩） | Open Ocean 鱼群 + 水色背景 |
| T-F | 表情倾向：抉择反馈从 19 张表情中按 tf 权重选取 | 表情 19 张 |
| J-P | 排布感：报告卡/图鉴布局规整度与徽标朝向 | whale-* 立绘姿势映射 |

- **16 型零新画**：avatar = 基础鱼形 × 四参数（CSS variables + filter），型号徽标复用 portraits.json 的 16 段画像；不需要为 16 型各画一张图，**数据驱动、可换皮**（梗过气时只换素材层，机制不动）。
- **接入点**：卡片流常驻 mascot（事件反馈动画 `fatfish-working`/`success` 帧）、阶段小结转场（whale-* 姿势）、终局报告主视觉。
- **招牌动词表登记**：能力名词「人格鱼 avatar」→ 产出：`src/viz/fish.ts` 渲染 + 全程 mascot → 断言：dims→参数纯函数单测 + 双端渲染冒烟（E2E）。

### 4.3 终局分享卡（P0，传播点）

- Canvas 导出 1080×1440 竖版图：人格鱼主视觉 + 终局雷达 + MBTI 型号 + 画像一句话 + 关键抉择 3 条 + 水印（`watermark.webp` 进水印池）。
- 对标重开模拟器的「人生总结」社交货币位（§二）；手机长按存图/桌面右键另存即分享。
- **招牌动词表登记**：「分享卡」→ 产出：终局面导出按钮 → 断言：导出函数单测（canvas stub）+ 实存图留痕。

### 4.4 场景与仪式感（P1）

- 阶段卡片背景水域按出生环境微变（城乡/年代 → Open Ocean 素材组合），B 端署名落 credits；
- 阶段小结图标用 Simple Worlds SVG（蟹/龟/鱼…对应阶段意象）；
- 事件卡「重大抉择」节拍强化：critical 事件进场用 `fatfish-working` 帧循环（key-moments 纪律：重大节点要有重量）。

### 4.5 许可红线与入库策略（D1 决策点，v2-M3' 出口门）

| 层级 | 素材 | 处置 |
|---|---|---|
| ✅ 可入库分发 | cc-by 两组、`upstream/dafeiyu-pet/`（MIT）、codex whale 系（署名许可） | 入库 + credits 署名 |
| ⚠️ 谨慎 | `fish/` 62 张处理版（底层梗图二创） | **建议入库** + README 已知限制声明（v1 已有同类先例）；商用风险自担 |
| ❌ 永不入库 | 梗图原图（授权待核实）、fatfish GIF 原件（上游无 LICENSE） | 仅本地留底，不进 git、不进 dist |

- **D1 决策点**（发布范围三选一，待拍板）：A 保守 = 仅 CC-BY/MIT 组公开；**B 标准 = A + fish/ 处理版 + whale 系，配已知限制声明（推荐）**；C 激进 = 再加 GIF 原件（不建议）。
- **新增门禁**：`tools/check-assets-license.mjs`——扫描 dist 与 git 跟踪的素材 ⊆ 许可白名单 + credits 文件含必需署名行，白名单外即 FAIL（v2-M3' 落地，同提交）。
